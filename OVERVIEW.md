# This branch has two instances of euro-office
 - one in ENV2
 - one in ENV3
They **do not** share their database/directories!

# Defaults
 - This demo tries to preseed all the variables - see `./base_install_branch_specific.conf` for the defaults. You can permanently override the defaults by copying the file to `./base_install_branch_specific_custom.conf` - this will never be overwritten by a `git pull`.

# NextCloud Integration
 - Please read the official euro-office documentation (https://euro-office.github.io/documentation/integration/nextcloud/) for instructions on how to set up NextCloud integration

# Backup
 - Please read the official euro-office documentation (https://euro-office.github.io/documentation/introduction/overview/) for instructions on how to backup and restore your euro-office instance data.
